# CEAN
1. Home Page
 The home page introduces CEAN and explains the purpose of the platform. It provides quick access to
 reporting environmental issues and tracking complaints.
2. Environmental Issue Reporting
 Citizens can report environmental problems using an online reporting form. The user can select the type
 of environmental issue they want to report.
3. Environmental Categories
 • Air Pollution
 • Water Pollution
 • Solid Waste
 • Noise Pollution
4. Location Entry
 The user enters the location where the environmental problem occurred. This helps identify the area
 affected by the issue.
5. Problem Description
 Users can provide a description of the problem, including useful information about what they observed.
6. Photo Upload
 The reporting form allows users to attach a photograph as supporting evidence for the environmental
 complaint.
7. Complaint ID Generation
 After submitting a report, the website generates a complaint ID. The ID can be used to identify the
 submitted complaint.
8. Complaint Tracking
 Users can enter their complaint ID in the tracking section to check the current status of their complaint.
9. Statistics Display
 The website displays statistics such as total reports, resolved reports, and active environmental
 hotspots to provide an overview of reported issues.
10. Responsive Design
 The website is designed to work on different screen sizes, including desktop computers, tablets, and
 mobile phones.
11. Simple User Interface
 The interface is designed to be simple and easy to use so that citizens can submit an environmental
 report without complicated steps.
12. Future Database Integration
 The current website is a frontend prototype. It can be connected to a database such as Firebase in the
 future to permanently store complaints, photos, locations, users, and complaint statuses
